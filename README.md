# scheduleapp_STG
About: A python-based scheduling web application with streamlit.

## Dependencies
Python and pip is required to run this script. As well as pandas and streamlit. List of dependencies can be found in "requirements.txt".

## How to start the application
When downloading this repository manually, simply navigate to your downloads folder and double click on the "run.bat". When bashing, the application should run automatically.

## Navigating the scheduling application
To enter your inputs, simply click on the button below the page's form. When entering a completely new username, you will be automatically directed to a sign up page. When creating a new appointment and adding guests, add guests based on their full case-sensitive names, and always click on the "Add Guest" every time you enter a user's name.
